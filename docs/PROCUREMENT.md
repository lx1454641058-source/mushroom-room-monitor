# 展示箱与液体输送采购设计

新增CO2、低压加热及制冷的采购条件和GPIO见[六路扩展设计](EXTENSIONS.md)。本页为基础四路采购部分，需与扩展清单合并；现有空调仍不接入小型展示箱方案。

本方案用于小型毕业设计展示箱。用户已确认保留抽水和营养液释放，并允许重新设计采购；未提供现有器件完整型号。本文件给出采购规格和可核查参考，不代表已下单或已完成实物匹配。

## 总体布置

建议采用约40～60升透明展示箱作为工程演示空间，尺寸是设计建议，不是已经验证的栽培容积。一侧设置进风口，另一侧上方设置12V直流排风扇，风机与电路放在喷雾范围之外。摄像头固定在箱外观察窗，传感器避开喷口。不能据小箱演示证明真实菇房换气、降温或产量效果。

现有空调不接本版输出；“四叶箱”的具体设备未确认，不据此设计市电控制。温度保持监测功能，通风不能替代独立制冷。

水路A：清水储罐 → 清水蠕动泵 → 雾化水箱。储罐有低液位开关，水箱有低水位和高水位开关。低水位保护雾化器，高水位禁止继续补水。

水路B：独立带盖营养液储罐 → 营养液蠕动泵 → 独立接收容器。源罐检测缺液，接收容器检测满液。管路与雾化水路分开，不把营养液雾化。首次调试两路都用清水，真实营养液配方、适用菌种和投加量另行确认；本程序不根据运行秒数承诺实际毫升数或栽培效果。

蠕动泵通过挤压软管输送液体，方便把电机与液体分开。储罐、泵和接收容器安装在接水托盘上，出口固定并避免形成跨液位的持续虹吸；断电后观察是否仍有液体流出。

## 固件对应引脚

| GPIO | 信号 | 闭合或输出含义 |
|---|---|---|
| 21 / 22 | AHT20 SDA / SCL | 3.3V I²C，不接5V上拉 |
| 25 | 雾化驱动IN | 高电平开，低电平关 |
| 26 | 风机驱动IN | 高电平开，低电平关 |
| 32 | 清水泵驱动IN | 高电平开，低电平关 |
| 33 | 营养液泵驱动IN | 高电平开，低电平关 |
| 27 | 雾化水箱低水位 | 足水闭合至GND，缺水/断线时断开 |
| 14 | 清水储罐低液位 | 有液闭合至GND，缺液/断线时断开 |
| 13 | 雾化水箱满液位保护 | 未满闭合至GND，已满/断线时断开 |
| 23 | 营养液储罐低液位 | 有液闭合至GND，缺液/断线时断开 |
| 19 | 营养液接收容器满液位保护 | 未满闭合至GND，已满/断线时断开 |

所有浮球输入使用内部上拉，闭合才允许相应动作。满液位触点与低液位触点的安装逻辑不同，必须实测；不能将“买到常开浮球”直接等同于满足本表。固件对断开立即撤销允许状态，恢复闭合连续1秒后允许人工重新操作。

负载电源不能接GPIO；开发板、非隔离驱动与低压电源按各模块手册连接信号参考地。泵电机需续流保护，不能仅因MOSFET模块标称大电流就假定已具备。接收高位开关应留出泵停止延迟和管内余液所需空间。

## 控制与实测步骤

1. 上传main.py、controller.py、liquids.py、aht20.py四个文件；无液体状态的旧固件仍可采集，后台禁止发送泵指令。
2. 先不接负载，验证四路上电为关闭，检查每个浮球闭合/断开对应页面状态。
3. 环境控制停止且源罐有液、接收容器未满时发送“抽水5秒”。确认真实泵启动并按时停止。
4. 发送“释放营养液3秒”，使用清水接入量杯，记录送液量。泵停后至少等待5秒，重复三次，报告各次结果而非只报平均值。
5. 分别在运行中模拟源罐缺液、接收容器满液与信号断线，确认停泵。恢复条件后不得自动重新启动。
6. 验证两路泵不能叠加、不能通过重复指令延长计时，环境控制与泵输送互斥；“全部停止”停止四路输出。
7. 断开USB并计时，确认最后一次心跳10秒内停止；断开环境传感器或液位输入也应触发对应保护。
8. 量杯测试和断电无续流通过后，才连接实际实验容器。完整填写ACCEPTANCE.md，记录视频与原始CSV。

清水泵1～30整数秒，营养液泵1～10整数秒；这是工程演示限制。当前不提供每天自动投加、体积换算、补水后自动重启环境控制或自动营养配方。
