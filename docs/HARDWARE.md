采购前核对雾化器、驱动与电源的电压、电流、开机方式。部分 USB 加湿器通电后仍需按键，不能直接满足本版开关控制。尚无已确认的执行器型号，因此这里给出信号分配，不编造通用电源端子接法。

AHT20 适合本项目短时演示；厂商指出长期高湿可能产生偏移，不能直接承诺在结露菌房中长期可靠。探头避开直接喷雾与冷凝水。依据：[奥松 AHT20 B2 手册](https://www.aosong.com/userfiles/files/media/AHT20%E4%BA%A7%E5%93%81%E8%A7%84%E6%A0%BC%E4%B9%A6%28%E4%B8%AD%E6%96%87%E7%89%88%29%20B2-0630.pdf)。

## 固件默认引脚

适用对象：**经典 ESP32-WROOM-32 开发板**。这里的号码是 GPIO 编号，不是排针的第几个位置。

| ESP32 | 对端 | 说明 |
|---|---|---|
| 3V3 | AHT20 VCC | 传感器模块应支持 3.3V；I²C 上拉不能接 5V |
| GND | AHT20 GND | 共同信号参考 |
| GPIO21 | AHT20 SDA | I²C 数据线 |
| GPIO22 | AHT20 SCL | I²C 时钟线 |
| GPIO27 | 浮球开关一端 | 开关另一端接 GND；足水闭合、缺水断开 |
| GPIO25 | 雾化驱动 IN | **高电平开启，低电平关闭** |
| GPIO26 | 风机驱动 IN | **高电平开启，低电平关闭** |
| USB | 电脑 USB | 串口 115200，8N1 |

如果模块引脚标注不同，以模块原理图核对后再接线。负载不能接 GPIO 或 ESP32 的 3V3 输出；由匹配的外部直流电源经过驱动模块供电。非隔离驱动一般需要共地，隔离模块按其手册接线，不一概短接。

选用能由 3.3V 信号驱动、掉电默认关闭的模块；核对输入下拉与电感负载保护。固件只能在运行后设置 GPIO，不能消除上电期间引脚悬空带来的误动作。演示采用低压直流设备，不自行接市电负载。水与电源、主板分开放置，保留手动断电开关。

## 固件文件

MicroPython 是运行在单片机上的 Python。先在开发板安装**与其型号匹配的官方稳定版**，然后将下面四个文件复制到板载文件系统根目录：

- `firmware/main.py`
- `firmware/controller.py`
- `firmware/liquids.py`
- `firmware/aht20.py`

官方入口：[ESP32 MicroPython 下载](https://micropython.org/download/ESP32_GENERIC/)、[ESP32 使用说明](https://docs.micropython.org/en/latest/esp32/quickref.html)。本次没有连接开发板、刷写固件或验证特定固件版本；不把最新版文档等同于已上板测试。

刷写前记录开发板型号和现有固件；擦除 Flash 会清除板上旧程序，因此不在不知道原内容时直接执行。可使用熟悉的 MicroPython 文件上传工具或编辑器。关闭该工具占用的串口后，再启动电脑后台；不要同时开串口监视器。

驱动按 AHT20 B2 协议读取，检查校准位、忙状态与 CRC。CRC 是检验数据传输错误的校验值。校准状态异常时报告传感器故障，不尝试未知版本的寄存器初始化；实物若出现此情况，先核对模块版本与供电。

## 首次上电验收顺序

1. **先不接执行器负载**。给开发板与传感器通电，确认温湿度不是空值。
2. 浮球置于缺水位置，确认页面显示缺水、不能启动；足水后等待约 1 秒再试。
3. 用指示灯或仪表验证 GPIO25/26 高低电平与页面一致，验证上电默认关闭。
4. 断电后接入匹配的低压驱动、风机与雾化装置，再通电。
5. 验证实际雾化、风机启停和缺水停止；软件状态只能证明发出了指令。
6. 拔除 USB：电脑应显示未知；最后一次心跳后 10 秒内固件关闭输出。重新连接不会自动重启控制。
7. 拔掉温湿度传感器，确认保护停机；恢复后人工启动。
8. 低湿持续不升时，应在单次连续加湿 120 秒后停机，检查雾化器容量、传感器位置与阈值。
9. 完成上述测试后，再记录至少一段连续运行数据用于论文实物实验。

## 本版控制边界

开机默认停止；每次重新启动开发板恢复演示参数 65/72%RH、通风周期 300 秒/开启 15 秒。参数没有写入 Flash，以减少调试复杂度和意外保留。

缺水、传感器异常、心跳超时或连续加湿超时都会关闭两路输出并取消启用状态，恢复条件后人工重新启动。固件使用 8 秒看门狗，处理器若卡住会重启；是否能让实物可靠断电仍取决于驱动的默认关闭设计。

这是一套可验收的毕设展示箱原型。大空间风量、制冷除湿、水路卫生、工业电气防护和长期无人值守可靠性不属于本版已完成范围。
