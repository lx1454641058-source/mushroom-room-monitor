# 蘑菇房智能体使用说明

新版还支持“启用温控与二氧化碳联动”“关闭温控与二氧化碳联动”“把温度下限设为18，上限设为24”“把二氧化碳下限设为800，上限设为1200”和“识别选定照片”，详见EXTENSIONS.md。先启动环境再启用温控联动，修改联动参数前关闭联动；识别使用页面选定照片和菌种。超限CO2通风优先于手动关闭风机。下方基础四路操作仍保留。

本版把中文指令转换为受限工具调用，执行结果来自现有控制后台。默认用于模拟演示；切换实物串口后调用同一控制链路，但实物尚未验收。

## 启动与操作

本地 Ollama 服务和 qwen3:4b 模型已就绪时，双击 start-agent.cmd。服务地址固定为 127.0.0.1:11435。启动前先在原后台窗口按 Ctrl+C 关闭旧的蘑菇房后台，避免端口重复占用。启动脚本不下载模型，也不自动安装或启动 Ollama。

网页打开 http://127.0.0.1:8770，在“蘑菇房智能体”输入指令并点击“发送并执行”，也可按 Ctrl+Enter。快捷示例按钮只填入文字，仍需发送。发送即代表执行该条明确操作，不另弹确认框。模型处理期间显示等待秒数，快速停止按钮保持可用。

建议依次演示：

1. 查询状态
2. 把湿度下限设为65，上限设为75，然后启动系统
3. 通风30秒
4. 请把风机切换成定时通风
5. 把通风周期设为60秒，每次通风10秒
6. 生成报告
7. 全部停止

以上数字仅供模拟展示，不是特定蘑菇品种的栽培处方。执行后核对实时状态、参数表和智能体消息中的“执行记录”。消息显示是本地模型规划还是明确指令快捷执行。

## 已开放工具

| 对象 | 指令与效果 |
|---|---|
| 环境和设备 | 查询状态、查看当前参数、为什么不出雾；显示实时状态、参数和基于当前数据的原因说明 |
| 自动控制 | 启动系统；湿度上下限控制加湿，风机按周期运行 |
| 停机 | 全部停止；快速通道不等待模型推理 |
| 通风 | 通风30秒、关闭风机、恢复定时通风 |
| 液体输送 | 抽水5秒、释放营养液3秒；先全部停止环境控制，再单独发送；到时停止 |
| 参数 | 明确指定湿度上下限，或以秒为单位指定通风周期和时长 |
| 数据 | 生成报告、备份数据、查看照片 |
| 摄像头 | 开启摄像头、拍照保存、开启定时拍照、关闭定时拍照、关闭摄像头 |

摄像头动作在当前浏览器执行，需要浏览器权限和实际摄像头。先开启摄像头，再单独发送拍照指令。定时拍照固定每5分钟，页面需要保持打开。网页把实际执行结果回传后台；摄像头未开启时不会声称照片已保存。

温度目前只监测。清水泵和营养液泵支持单次限时控制：先全部停止环境控制，再发送“抽水5秒”“释放营养液3秒”；支持“停止抽水”“停止营养液泵”。两路泵不能同时运行，需有液且接收容器未满，到时或保护触发停止。升降温执行器尚未接入。摄像头用于记录，尚未自动识别长势。

## 执行边界

- 一条指令最多4步，先校验整份计划再执行；参数必须来自用户给出的数字并符合现有范围。
- 每条消息独立理解，不记忆上条参数；不要只发“改成75”或“继续”。请写清对象、单位和动作。
- 含糊、否定、假设和询问操作方法的语句不会触发设备写操作。查询与控制请分开发送。
- 摄像头操作单独发送；手动通风仅支持30秒，其他持续时间请调整周期参数。混合多个数字的手动通风组合语句可能被保守拒绝，请拆开。
- 缺水、传感器异常、通信失效、连续加湿超时保护始终由控制程序处理，模型不能绕过。
- 规划期间如果人工操作设备、切换模拟场景或开发板重启，旧的控制计划取消，防止停止后被迟到的计划重新启动。
- 同一请求编号在后台最近64条缓存内只执行一次；后台重启后缓存消失，网页不会自动重发失败的请求。
- 多步执行中途失败会说明已完成的步骤，不自动回滚，也不重试剩余操作。
- “全部停止”仍是软件控制；若已有底层命令在等待应答，可能返回忙，断线也无法保证物理设备已停。以实时状态、板端保护和实际负载为准。

## 模型未运行时

不传模型参数的 start-demo.cmd 仍支持固定指令，如“查询状态”“启动系统”“全部停止”“通风30秒”“生成报告”。以下参数模板也可直接解析，数字可以替换，支持小数；会先验证范围再执行：

- 把湿度下限设为65，上限设为75，然后启动系统
- 把湿度上限改为75.5%
- 把通风周期设为60秒，每次通风10秒
- 把每次通风时长设为10秒

支持“设为、设置为、改为、改成、调到”等模板用词。必须是完整指令，参数使用阿拉伯数字，通风时间使用秒；“湿度设为75”等未说明上下限的语句不猜测执行。精确匹配模板优先于模型，明确显示“快捷执行”；其他表达仍由模型解析。

“为什么不出雾”是只读查询，不会启动系统。状态说明区分停止、缺水、传感器异常、达到湿度上限、上下限之间和可能等待最短停机间隔。没有读取到有效实时数据时只报告未知，不依据旧数据诊断；没有负载反馈，不能从加湿指令推断实物一定出雾。

模型连接失败、超时或计划不合法时显示原因，设备控制不会凭猜测继续。页面“本地模型 + 工具执行”表示后台已配置模型，不代表模型服务健康检查通过。

已有的“本地模型建议”仍是只读统计建议入口，与本页可执行指令分开。
