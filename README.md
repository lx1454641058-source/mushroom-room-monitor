## 本人责任

负责小型展示箱系统方案、控制规则、AI 工具权限和交付材料，拆分 ESP32、电脑后台、六路执行器与智能体职责；借助 AI 推进网页、固件和模拟场景。

## 具体任务 1：把控制条件写清

设计湿度上下限、最短停机间隔、加湿通风、限时泵、CO2 与温控互锁。模型只能把明确指令转为受限工具调用，不能修改保护逻辑或自主决定栽培参数。

## 具体任务 2：处理缺水与断线

将缺水、满液、传感器异常、连续加湿超时和通信超时转为保护流程。限制泵运行时长，恢复后要求人工重启；区分软件停止指令与独立硬件急停。

## 具体任务 3：准备交付与演示

整理采购接线、串口通信、项目报告和答辩说明；支持趋势、事件、CSV 导出与备份。建议演示湿度降低启动、升高停止、缺水拒绝启动、断线状态未知和恢复流程。

## 已有成果与缺口

已有六路控制软件演示、规则设计和交付材料。实物采购接线、执行器联调、摄像头独立测试及图像成熟度 / 病害识别效果仍待验证，不计真实栽培成果。暂无已核实公开链接。
